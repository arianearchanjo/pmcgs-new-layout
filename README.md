# 🏛️ Templates: Novo Layout PMCGS

Este repositório contém os templates desenvolvidos para a modernização da interface da **Prefeitura de Campina Grande do Sul**. O projeto tem como foco principal aprimorar a experiência do cidadão e **elevar o índice de transparência municipal**, facilitando o acesso à informação e aos serviços públicos de forma clara e intuitiva.

**Desenvolvedora:** Ariane da Silva Archanjo (Estagiária de Desenvolvimento de Sistemas).
